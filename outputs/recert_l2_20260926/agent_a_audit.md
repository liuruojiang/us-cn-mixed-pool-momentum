# L2 独立审计 A：历史可知性、成交时钟及现金/份额回放

## 结论

- **在正式代码已声明的「当日收盘信号、当日收盘模型成交」口径内，账户逐日核算一致。**独立实现没有导入正式模块或调用 `run_staged_entry`、`build_curves`、`calc_performance`。使用 L1 冻结 2026-09-24 价格面板，在 3,594 行上重算信号、持仓、现金、ETF 份额、费用、净值和指标。与正式新曲线的目标/前后持仓/换手/成本逐行全同；收益最大绝对差 `4.08e-16`，NAV 最大绝对差 `1.56e-13`，按 `rtol=1e-10, atol=1e-11` 无首差异。
- **绩效窗口存在小幅年化分母错误。**正式 `calc_performance` 把窗口首行净收益置零，却将含该首行在内的 `N` 行都作为年化分母。按手册「首日已形成 NAV 为基点」口径，应按 `N-1` 次变化计算。两位独立审计 Agent 交叉质询后确认 Full 的首行 `NAV=1`、`return=0`，无前一价格 bar、无持仓或成交；它也是基点而非可观测 close-close 收益日。当前正式五窗年化低估 `0.0096–0.3172` 个百分点；最大回撤不变。本层建议修正报告指标口径并标注旧指标失效范围，不需改策略信号与交易账户。
- **历史执行可行性没有通过。**正式信号读取当日收盘价格，并在同一个收盘价记模型成交；这是冻结研究假设，不是收盘后可实际下达的同价成交。做了一次只把信号延后一行、在次日收盘成交的对抗回放，1Y 年化从 `63.26%` 降至 `11.98%`（都按 `N-1`），说明时钟假设对结论有重大影响。这个延迟回放是时钟敏感性诊断，不是新正式版本，也未模拟次日开盘、QDII 溢价或流动性，不能作为真实可交易收益估计。

## 数据、代码及假设

- 版本：`poe_subd_six_etf_v1_3_bot.py`，六只中国上市 ETF，25 日含当日价格加权对数回归，`0.5 < Score < 5.5`，`R² >= 0.25`，Top 1，全仓/空仓，现金收益 0。
- L1 输入：`prices_raw_qfq_through_20260924.csv.gz`、`prices_aligned_qfq_through_20260924.csv.gz`、`price_ffill_flags_through_20260924.csv.gz`；六列，2011-12-09 至 2026-09-24，共 3,594 行。两处单只缺价前填为 2021-02-08 的 `159915.SZ` 与 2025-01-23 的 `513030.SH`，这两日均未交易相关资产。价格来源和前复权语义限制沿用 L1 记录。
- 单边费用/滑点 `0.1%`，资产切换双边换手为 2，日收益先由旧持仓享受当天 close-close 变化，随后在收盘以新目标成交并扣费。每日成本金额为收盘交易前权益乘以 `turnover × 0.001`；新 ETF 份额为扣费后权益除以当日收盘价。现金、份额及收盘权益逐日守恒；成本累计为按实际 NAV 规模计的 `5.44336` 个初始资本单位，不能当作单次费用率。
- 真实报价和官方交易日历已由 L1 核过；本层验证的是对该固定面板的计算。无基准、无实盘成交、无盘口容量/涨跌停/T+1 细节仿真。

## 时钟与拒错反例

正式路径 [评分](../../poe_subd_six_etf_v1_3_bot.py) 使用 `prices.iloc[idx-24:idx+1]`，即当日收盘价格；账户计算先使用旧持仓当日收益，再计算当前收盘成交费用，之后新持仓从下一行收益开始。2012-02-14 首次入场：旧持仓现金，当日净收益应为 `-0.1000%`，而新 ETF `159915.SZ` 同日 close-close 收益为 `-0.4178%`；若错误地将新资产当日收益算入，当日净收益变为 `-0.5174%`。2013-08-30 首次 ETF 切换：旧 `159915.SZ` 当日收益 `-2.9826%`，新 `518880.SH` 当日收益 `-0.3219%`；正确双边成本后净收益 `-3.1766%`，错误地套用新资产当日收益会变为 `-0.5212%`，只扣一边费用会变为 `-3.0796%`。正式曲线均符合正确的模型记账分支。

从信号的真实可知时间看，2012-02-14 的首笔买入只能在当日收盘价出现后才确定；当日收盘同价成交需要未说明的机制。若前一天的信号到下一交易日收盘才成交，独立回放第一次持仓差异就是 2012-02-14，最终 NAV 由 `44.1889` 变为 `25.2589`。这一反例不推断未来数据泄漏到模型收益中；它指出信号生成与假定成交在同一收盘时点的可执行性缺口。

同一路径将成本率置零后最终 NAV 为 `78.4102`，所有日期无成本 NAV 均不低于含成本 NAV。独立账户含成本最终 NAV `44.1888738857`，交易日 `379`，其中双边切换 `194`。正式曲线 `turnover` 和 `cost` 每行一致，没有遗漏双边费用。
