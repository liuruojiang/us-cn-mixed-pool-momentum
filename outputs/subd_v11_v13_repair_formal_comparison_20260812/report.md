# Sub-D V1.1 / V1.3 修复前后正式同输入回测

## 1. 范围与结论

- 截止日固定为 `2026-08-11`，避免混入 2026-08-12 尚未确认的数据。
- 基线为 `.codex_backups/20260812_114431` 中的修复前 Poe 代码；新版本为当前 Poe 代码。
- 每个策略只下载一次当前正式 loader 验证通过的价格矩阵，然后把完全相同的价格、交易日和 forward-fill 标记分别输入修复前后代码。
- V1.1 的历史曲线有小幅但真实的变化：实际敞口 hard-cap 在 73 日触发；全样本年化下降 0.0425 个百分点，期末复利净值下降 0.4416%。
- V1.3 的收益、净值、换手、成本、持仓和候选选择全部零差；raw score 最大差为 `6.76e-12`，属于浮点计算精度，不改变任何信号。

## 2. 代码与数据来源

### V1.1

- 正式入口：`poe_subd_six_etf_v1_1_bot.py` 的 `load_close -> align_prices_to_common_valid_date -> build_curves -> calc_performance`。
- 区间：2011-12-09 至 2026-08-11，共 3,562 个中国交易日。
- 调整方式：六只 ETF 均为 qfq/front-adjusted。
- 数据源：
  - `159915.SZ`、`159941.SZ`：Tencent fqkline。
  - `513030.SH`、`513520.SH`、`159985.SZ`、`518880.SH`：AkShare Eastmoney qfq。
- 参数：目标波动率 25%，波动窗口 80 日，最大实际敞口 1.5x，单边成本 0.1%。

### V1.3

- 正式入口：`poe_subd_mixed_pool_v1_3_bot.py` 的 `load_close -> build_curves -> calc_performance`。
- 区间：2007-01-04 至 2026-08-11，共 4,764 个中国交易日。
- 数据源与调整方式：
  - QQQ、GLD、KMLM：Yahoo Finance adjusted close。
  - 创业板代理 `CN_CYB_399006`：AkShare `stock_zh_index_daily` price index。
  - `159985.SZ`：Tencent qfq，并保留正式源交叉验证说明。
- 参数：target-vol 关闭，最大 scale 1.0x，现金年化 3%，单边成本 0.1%。
- 动态资产按自身首个可用日加入；没有上市前回填。

## 4. 验证

- 当前两个正式日度结果均通过各自 `prepare_daily_for_performance` 和 `calc_performance` 复核。
- CSV 往返后的最大指标误差：V1.1 `4.83e-12`，V1.3 `1.99e-12`。
- 日期严格递增且唯一；return、NAV、turnover、cost 全部有限。
- 全仓库测试：`python -m pytest -q tests` -> `495 passed, 1 warning`。
- 唯一 warning 来自 `fastapi_poe` 的 Pydantic 配置弃用提示。

## 5. 交易摩擦与限制

- 已包含：代码现行单边成本 0.1%、现行 target-vol/nav-defense/overheat/现金收益规则。
- 未包含：额外滑点、冲击成本、成交量容量、涨跌停实际成交、T+1 券商持仓约束、USD/CNY 换算。
- 原因：两个版本当前仅提供信号，不直接自动下单；本次目标是精确测量代码修复对既有历史回测的影响，而不是构造新的可成交 PnL 模型。
- V1.3 仍沿用现行中国交易日对齐与跨市场代理口径；US→CN 同日收盘不可执行性属于使用提示，不是本次 old/new 差异来源。
